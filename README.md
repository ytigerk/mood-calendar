# 기분 캘린더

하루 기분을 -10 ~ +10으로 기록하고 메모를 남기는 모바일용 캘린더입니다.

- **캘린더:** 날짜를 누르면 기분 점수와 메모를 기록할 수 있어요. 점수에 따라 칸 색이 바뀝니다 (빨강 → 주황 → 노랑 → 초록 → 파랑).
- **그래프:** 한 달 동안의 기분 흐름을 선 그래프로 보여줍니다.
- **설정:** 백업 내보내기/불러오기, 홈 화면에 추가 기능이 있습니다.

기록은 서버가 아니라 **사용하는 기기의 브라우저에만** 저장됩니다. 가끔 설정 탭에서 백업 파일을 내보내 두세요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면과 기능 전체 |
| `manifest.webmanifest` | 홈 화면에 추가할 때 쓰는 앱 이름·아이콘 정보 |
| `sw.js` | 인터넷이 없어도 앱이 열리게 하는 도우미 |
| `icons/` | 앱 아이콘 |
